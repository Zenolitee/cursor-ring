Cursor Ring editor

Tweak the look, hover a cursor to try it, then download an installable Windows pointer scheme.

Settings

Preview

Each cursor on a dark and a light background. Hover one to use it as your real pointer.

Guide

Make your scheme

  1. Change the settings on the left. The preview updates as you go, and your settings are saved in this browser.
  2. Give it a Scheme name so you can tell your versions apart (for example Cursor Ring Blue).
  3. Click Download scheme. You get a .zip named after your scheme.

Install it

  1. Unzip the download (right-click → Extract All).
  2. In the extracted folder, right-click install.inf → Install and accept the admin prompt. On Windows 11 it's under Show more options.
  3. Open Settings → Bluetooth & devices → Mouse → Additional mouse settings, then the Pointers tab.
  4. Pick your scheme in the Scheme list and click Apply.

What each setting does

  • Main colour: every cursor except Link Select. Link colour: the link (hand) cursor.
  • Glow: the soft halo. Set strength to 0 for a flat look.
  • Outline: the dark edge that keeps light cursors visible on white pages. Width 0 removes it.
  • Line thickness: scales every stroke (arrows, I-beam, spinners). Dot size and Link ring size change the round shapes.
  • Spinner arc and frame time: the length and speed of the Busy and Working animations (lower ms = faster).

Good to know

  • Each cursor is saved at 32, 48, 64, 96 and 128 px, so it stays sharp with the pointer size slider.
  • While the Cursor Ring app is running, it swaps the normal pointer for its own dot. To keep your Normal Select cursor, open Ring settings... from the tray and set dot = false.
  • To update a scheme, install again with the same name: the files are replaced. Then re-select it in Pointers and click Apply.
  • To remove one, pick another scheme in Pointers, select yours and click Delete, then delete C:\Windows\Cursors\<scheme name>.
  • Reset brings back the original look.
